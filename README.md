## Featured Projects

### [TrainDex - NYC Subway Spotting Game](https://github.com/CodeReDarsh/TrainDex)

[View the live website](https://traindex.wiki)

An AI-powered subway spotting game developed during a hackathon, designed for NYC railfans to discover, identify, and collect subway rollsigns as digital trading cards.

Inspired by collectible card games and the excitement of spotting rare trains, TrainDex combines computer vision, a structured subway signage database, and interactive gameplay to make exploring NYC's transit system more engaging.

**My contributions focused on backend development and database infrastructure:**

- Developed a structured catalog of NYC subway rollsigns, including route identifiers, historical variants, and reference images
- Built database infrastructure using Python, FastAPI, and SQLAlchemy to organize and retrieve subway signage records
- Worked on AI-assisted rollsign identification using Google's Gemini API to analyze uploaded train photos and match signage against catalog records
- Supported identification of visually similar rollsign variants through structured metadata and reference-image matching

**Additional project features:**
- Collectible digital cards generated from real-world subway sightings
- Route collections, pixel pets, and historical subway signage references
- Live subway service information using MTA data
- Browser-based storage for saved cards and photos

**Tech:** Python, FastAPI, SQLAlchemy, PostgreSQL, Gemini API, React, TypeScript, MTA APIs
